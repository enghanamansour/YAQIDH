# نموذج عمل يَقِـــظ (Business Model Canvas)

الملفات: `canvas-ar.png` / `canvas-ar.pptx` (عربي)، و`canvas-en.png` / `canvas-en.pptx` (English).
كل الأرقام **تخطيطية** وتُراجع بعد أول تجربة مدفوعة. الأسعار قبل ضريبة القيمة المضافة (15%). الإيراد غير محسوب من الاحتياج.

## 1. شرائح العملاء
- الشركات التقنية والشركات الناشئة (السعودية والخليج).
- فرق الأمن السيبراني وفرق DevSecOps.
- المستخدم: فرق التطوير. المقرّر: الأمن السيبراني. الميزانية: مدير التقنية أو الأمن.

## 2. القيمة المقدَّمة
- القرار بيد إنسان، والذكاء الاصطناعي يشرح فقط.
- فحص الجودة والفحص الأمني بمسار واحد.
- شرح كل ثغرة ومشكلة بالعربي.
- إعادة فحص تلقائية تثبت الإغلاق.
- سجل أدلة، والموافقة مربوطة بنسخة الكود.
- تقليل دورة المراجعة (فرضية تحتاج قياس).

## 3. القنوات
لينكدإن · البيع المباشر · شراكات الشركات.

## 4. علاقات العملاء
تجربة مدفوعة 90 يومًا · دعم فني بساعات العمل · تحديثات دورية · برنامج شريك التصميم.

## 6. الأنشطة الرئيسية
تطوير المنصة والفحص الأمني · الصيانة والتحديث · التركيب وربطها بأدوات العميل · الدعم الفني · المبيعات وتشغيل التجارب · الامتثال القانوني.

## 7. الموارد الرئيسية
- موجود: فريق من 4، ومنصة تعمل، وأدوات الفحص.
- مطلوب (بالتمويل): مطوّر إضافي، ومستشار أمن، ومختص مبيعات.
- تقني: 4 أجهزة كمبيوتر، واستضافة، ونموذج ذكاء اصطناعي، وقواعد فحص مرخّصة.

## 8. الشركاء الرئيسيون
- تقنيون (بدون عقود رسمية): Semgrep وTrivy وGitHub، ومزوّد نموذج الذكاء الاصطناعي.
- مطلوبون: شريك تصميم (أول عميل)، ومستشارو أمن سيبراني، ومستشار قانوني (ترخيص القواعد).
